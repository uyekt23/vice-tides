Vice Tides — an original open-world crime game set in the island city of Palmera Bay. Explore on foot or by car, run missions for a fixer, take taxi fares, hunt hidden packages, and outrun the police as your wanted level rises. It plays fully offline in a desktop browser from its own files: no build step, no server, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome — or simply open game/index.html directly.
